# Mockups

Source files of the clickable mockup canvas (Claude artifact): https://claude.ai/artifact/NgLwzuKNsMfrGEAL3QH7FF (private to the owner).

| File | Screen |
|---|---|
| `Main.dc.html` | Today (home) with red-flag banner, next-slot card, value tiles and top insights |
| `QuickLog.dc.html` | Quick Log: slot, time, vitals, context tags, symptom sliders, dose checklist |
| `Trends.dc.html` | Systolic chart with target band and regimen-change marker, per-slot in-range table |
| `Insights.dc.html` | Expandable insight cards with evidence and discussion points, regimen-change evaluations |
| `Regimen.dc.html` | Current regimen grid, approx. drug timing, version history |
| `Doctor.dc.html` | Doctor view / A4 print summary (light, solid surfaces) |

These are the **visual reference** for the React build: colours, type (Manrope, tabular numerals), spacing, radii and the glass treatment. They aren't app code. Data and behaviour follow `meta/SPEC.md`.

Theme tokens used in the mockups (dark): `--bg #0B1220`, `--surface rgba(255,255,255,0.06)`, `--border rgba(255,255,255,0.12)`, `--text-primary #E8EEF7`, `--text-muted #9AA8BC`, `--accent #2DD4BF`, `--gain #4ADE80`, `--warn #FBBF24`, `--loss #F87171`, regimen-change marker `#A78BFA`.
