# Security

Health Tracker is a single-user app: all health data stays in the browser's local storage on the user's device and is never sent anywhere. The app makes no runtime network requests.

To report a security problem, please open a [private security advisory](https://github.com/Evox402/HealthTracker/security/advisories/new) instead of a public issue.

Only the repository owner can merge changes. Contributions from forks are welcome as pull requests but are reviewed before anything runs or merges.
